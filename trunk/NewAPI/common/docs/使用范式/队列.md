# 队列组使用范式

> **范围**：环形队列组 7 个类（que_comm/que_swr_buf/que_mth_buf/que_proc_buf/que_swr_fixed/que_mth_fixed/que_spw_fixed）的独立使用模式。
> **边界**：队列组独立，不依赖内存池/线程。组合点见 §7（只点明不展开）。
> **源码基线**：include/que_*.h + src/que_*.cpp

## 1. 命名约定（选型前提）

类名按「写读拓扑 + 数据形态」编码：

| 命名段 | 含义 |
|---|---|
| `swr` | 单写单读（Single-Write-Single-Read）|
| `mth` | 单进程多线程并发读写（Multi-Thread）|
| `proc` | 多进程变长（Multi-Process）|
| `spw` | 单进程写 + 多进程读（Single-Process-Write）|
| `_buf` | 变长数据 |
| `_fixed<T>` | 定长数据（POD 模板）|

接口后缀：无后缀=单线程版；`_mth`=多线程版（CAS+忙等）；`_mp`=多进程版（que_proc_buf 独有，含崩溃检测）。

**变长 vs 定长**（指**存储数据形态**，不是队列大小）：
- 变长（`*_buf`）：存储任意长度字节流，`write_get(o_data, len)` 指定长度；**不存数据长度**，读者须自备长度知识
- 定长（`*_fixed<T>`）：存储固定大小对象，以 `sizeof(T)` 为步长；`T` 必须 **POD**（值拷贝传递）

**POD 限制**：定长队列的 `T` 必须 POD（无虚函数/无复杂构造析构），因队列用 memcpy/值拷贝传递。变长队列存字节流（memcpy），投递对象时对象也应可 memcpy（本质 POD）。**队列容量**（`init(que_size)` 的大小）是另一回事，必须 2 的幂（见 §5）。

## 2. 选型决策树

```
跨进程？
├─ 否（单进程）
│   ├─ 写/读端各 1 线程？
│   │   ├─ 变长 → que_swr_buf
│   │   └─ 定长 → que_swr_fixed<T>
│   └─ 多线程并发
│       ├─ 变长 → que_mth_buf
│       └─ 定长 → que_mth_fixed<T>
└─ 是（跨进程共享内存）
    ├─ 变长 + 多写多读 + 需崩溃恢复 → que_proc_buf
    └─ 定长 + 单进程写 / 多进程读 → que_spw_fixed<T>
```

| | 变长 | 定长 |
|---|---|---|
| 单写单读 | `que_swr_buf` | `que_swr_fixed<T>` |
| 多线程并发 | `que_mth_buf` | `que_mth_fixed<T>` |
| 多进程 | `que_proc_buf`（多写多读+崩溃恢复）| `que_spw_fixed<T>`（单进程写+多进程读）|

**关键差异**：`que_proc_buf` 是唯一支持多进程并发写（`write_mp`）且带崩溃检测的；`que_spw_fixed` 只支持单进程内多线程写、多进程只能读。变长队列（`*_buf`）**不存数据长度**，读者须自备长度知识；定长队列以 `sizeof(T)` 为步长。

## 3. write/read 配对规则

### 3.1 通用配对

- **两步零拷贝写**：`write_get(o_data, len) → getpos(>0=成功, 0=满)` → 填 `len` 字节 → `write_cmt(getpos, len)`
- **一步 memcpy 写**：`write(data, len)` / 多线程 `write_mth(data, len)`
- **读**：`read_get(o_data) → getpos(>0=成功, 0=空)` → 处理 → `read_cmt(len)` 或 `read_cmt(next_pos)`；定长可 `pop(T*)` / `pop_mth()`

### 3.2 各队列配对表

| 队列 | 单线程写 | 多线程写 | 单线程读 | 多线程读 |
|---|---|---|---|---|
| que_swr_buf | write_get/write_cmt 或 write | — | read_get/read_cmt(len\|next_pos) | — |
| que_mth_buf | write_get/write_cmt | write_get_mth/write_cmt_mth | read_get/read_cmt | read_cmt_mth(next_pos) |
| que_proc_buf | write_get/write_cmt | write_get_mth/write_cmt_mth；**多进程 write_mp** | read_get/read_cmt()\|read_cmt_pos | read_cmt_mth(next_pos) |
| que_swr_fixed<T> | write_get(T&)/write_cmt 或 write | — | read_get(T&)/read_cmt 或 pop | — |
| que_mth_fixed<T> | write_get/write_cmt | write_get_mth/write_cmt_mth | read_get/read_cmt 或 pop | **pop_mth** |
| que_spw_fixed<T> | write_get/write_cmt | write_get_mth/write_cmt_mth（仅写进程内）| read_get/read_cmt 或 pop | read_cmt_mth（**无 pop_mth**）|

**注意**：`que_proc_buf` 的位置版读提交是 `read_cmt_pos(next_pos)`（非 `read_cmt(int64)`，与其他队列不同）。变长队列**无 pop**（不存长度）。

### 3.3 返回值

`write_*`/`write_get_*`/`read_get`/`pop*` 返回 `int64 > 0` 为位置，`0` 为满/空。

## 4. 跨进程队列语义（que_proc_buf / que_spw_fixed）

### 4.1 创建者 vs 打开者

`init(..., is_create)` 的 `is_create` 区分：
- **创建者**（`is_create=1`，写进程）：映射共享内存，首次或 `is_continue=0` 时 `init_set()` 初始化控制结构；`close(is_create=1)` 释放映射（`unmap_shm`）
- **打开者**（`is_create=0`，读进程）：`while(info->mask==0) sleep_us(300)` 忙等创建者初始化完成，校验 `mask+1==tnum`；`close(0)` 不释放

**铁律**：写进程必须是创建者（`close` 默认 `is_create=1`，打开者必须显式传 0，否则 `unmap_shm` 影响其他进程）。

### 4.2 op_pid 崩溃检测（que_proc_buf 独有）

每个数据块带 `proc_buf_head{user_len, mem_len, op_pid}`：
1. `write_get_mth` 抢位后填 `op_pid=本进程pid`
2. `write_mp`/`write_cmt_mth` 用 CAS 推进 `wrcmt`，要求前序已提交
3. 若前序写者卡住，`check_cmt_write` 用 `comm_utils::exist_pid(op_pid)` 判进程存活：存活=提交慢继续等；不存活=崩溃，CAS `discard_pos` 抢占恢复，把崩溃块标记 `op_pid=PROC_BUF_PID_INVALID(-11)`，推进 `wrcmt` 跳过
4. `read_get` 遇 `op_pid==INVALID` 块自动跳过
5. **崩溃块数据丢失**（恢复代价）

`que_spw_fixed` 无崩溃检测（单进程写，崩溃由外部保证）。

## 5. 容量要求

### 5.1 2 的幂 + mask（所有队列通用）

`init(que_size)` 的 que_size **必须 2 的幂**（内部 `calc_power` 向上取整，`mask=tnum-1`，`pos & mask` 位与寻址）。非 2 的幂 → mask 失效、数据错乱。

### 5.2 变长队列回环

变长队列 `write_get` 跨缓冲区末尾时跳回起点，`roundend` 记录旧末尾。`init_set` 中 `wrcmt/rdcmt` 初值 `CACHE_ALIGN_SIZE`(64) 非 0（避免与"空"混淆，写位置 0 被跳过）。定长队列无此复杂度（步长固定）。

### 5.3 满判定

- 变长：`tc + len - rdcmt > mask` 即满（保留策略，不超过一圈）
- 定长：`wr - rdcmt > mask` 即满（**保留 1 槽**，实际可用 = `tnum - 1`）

## 6. 线程安全边界

- 所有队列**无 mutex/spinlock**，靠 `atomic_load64/store64/cas64/fetch_add64` + `CPU_PAUSE` 忙等
- `que_mth_*` 多线程安全**仅限 `_mth` 接口**；无后缀接口多线程下调用会数据损坏
- 多线程写顺序保证：`write_cmt_mth` 忙等 `wrcmt==get_pos`（前序全提交）才推进，保证读端看到的 `wrcmt` 之前数据全就绪
- `reset_pos`/`close` 必须在无任何读写时调用
- 队列对象 `alignas(CACHE_ALIGN_SIZE)`(64) 避免伪共享

## 7. 与其他组的组合点（不展开）

队列组独立（只 include comm_sys/matomic/mutils/comm_errno/que_comm，无内存池/线程依赖）。缓冲区来源：`init(que_size)` 自管（`aligned_malloc`）或 `init(shm_addr,...)` 外部内存。

组合点：
- **+ 内存池**：定长队列投递对象指针/POD 值拷贝；变长队列投递字节流或指向内存池对象的指针。组合点在"队列载荷=池对象句柄"
- **+ 线程**：队列作线程间传递通道，线程用 `write_mth`/`pop_mth` 并发接口。队列自身不创建线程
- **+ 跨进程**：`que_proc_buf`/`que_spw_fixed` 通过共享内存名 `pname` 跨进程寻址，进程间需一致 `pname`+`que_size`+`align_byte`

## 8. 避坑

1. **容量必须 2 的幂**：mask 机制要求，否则 `pos & mask` 错乱
2. **变长队列不存长度**：读者必须知道每条消息长度，`read_cmt(len)` 提交**匹配的对齐长度**；提交错长度 → `rdcmt` 偏移错乱 → 后续全读错位。`que_proc_buf` 的 `read_cmt()` 无参版从 head 读 `mem_len` 可避免
3. **read_cmt 长度必须匹配 write_cmt**（变长）
4. **配对错误后果**：`write_get` 后不 `write_cmt` → 位置占用未发布，多线程卡死/单线程假满；`read_get` 后不 `read_cmt` → `rdcmt` 不推进，假满
5. **回环点忙等**：`write_cmt_mth`/`pop_mth` 内层自旋 `QUE_LOOP_BUSY_COUNT`(50000)，高并发 CPU 空转（设计取舍）
6. **que_spw_fixed 限制**：不支持多进程 pop 读；写进程必须是创建者
7. **que_proc_buf 崩溃恢复丢数据**：`discard_pos` 到新 `wrcmt` 之间数据丢失，业务须容忍
8. **reset_pos/close 时机**：必须无读写活动时调，否则位置错乱
9. **init 必须配 close**：共享内存由创建者 `close(1)` 释放；漏 close → 共享内存泄漏
10. **定长队列容量 -1**：保留 1 槽，可用 = `tnum - 1`
