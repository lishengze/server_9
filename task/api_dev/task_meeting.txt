回答:

1. 当前个微撤单规则:
    个微撤单请求对于API来说，只需要 orig_clordno[个微柜台内部生成编号]， 
    当前 api 里的代码需要改动，在委托响应里把这个编号通过 order_sys_no 返回给客户，然后客户在撤单请求里使用这个编号即可。

2. 个微是否支持客户私有号撤单：
    不支持

3. 非加速业务的撤单，怎么转发到 98 柜台:
    撤单请求统一先到个微， 个微判断不是当前柜台的委托，则通过DSE转发到 98 柜台。

4. 对于api 的字典， 98和个微无法保持一致，98柜台相对复杂，需要的字段多，所以考虑以个微的字典为准。
    98柜台根据个微的字典，做映射。
