    任务 -- 性能测试:
        任务背景: 当前业务测试已经完成，现在需要进行性能测试，测试当前系统的性能，
        1. 现在主要测试对接 FTE 柜台的，委托请求这条通路的性能表现。
        2. 测试相关的配置,也是通过 json 配置文件的形式存储。现在主要的配置项是:
            1. 测试时长，单位是秒，默认是 10 秒。
            2. TPS,即每秒的发单量，匀速发单的模式，即每笔发单的时间间隔是 1/TPS 秒。
        3. 测试的步骤：
            1. 在 OrderReq 中添加两个临时的属性 uint64_t 型，时间单位为纳秒，一个是到达 api 时间，一个是离开 api 时间。
            2. 在 api 的请求处理函数中，在请求到达 api 时，记录当前的时间，并赋值给到达 api 时间。
                在请求离开 api 时，记录当前的时间，并赋值给离开 api 时间。
            3. 收集所有请求的到达 api 时间和离开 api 时间，计算出每个请求的耗时。
            4. 分析指标:
                平均值, 50分位，75分位，90分位，最大值，最小值，标准差
            5.将分析的结果输出到专门的文件中，方便后续分析。
        4. 测试脚本开发：
            1. 需要编写一个专门的测试脚本，在测试进程启动后，进行对应的 隔离CPU 和 绑定CPU 操作，确保测试进程的性能测试结果是准确的。
            2. 这里就需要测试程序启动后，等待一段时间，再开始进行性能测试，确保已经绑核成功。
            3. 测试脚本中的 隔离CPU 和 绑定CPU 操作 ，要做成通用的，方便在不同的服务器上进行性能测试。 


        5. 现在实现的思路有问题， 
            1. 应该是在之前功能测试的基础上，增加一个性能测试的模块，专门用于测试 对接 fte 柜台委托请求的性能表现。
            2. 通过详细的参数配置，来确认是否开启性能测试 和 开启性能测试后采用什么样的具体参数和案例进行测试。
            3. 然后再按照之前约定的条件，进行相关的具体测试配置和测试案例的编写还有模块的开发。
