## 对比分析

### 5. 复测整体结论

- **API 内部延迟**：GW现有<GOne < GW单客户 < GW多客户（平均值/P50/P90 均成立）
- **网卡全链路延迟**：GW现有<GOne < GW单客户 < GW多客户（平均值/P50/P90 均成立）
- **新框架劣势**：内部协议转换，发送请求前 队列压入取出，增加耗时。
- **GW 与 GOne 对比**:  GW内部转换字节多于GOne 并且校验和算法比GOne 复杂，GW 单链接多客户相比GW 单链接单客户 多了map读取的耗时。
- 四对象在系统空闲时均达到极低延迟（API 内 P50 < 230ns，网卡全链路 P50 < 870ns）
