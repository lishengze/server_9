- **工作日志**：任务开始前先 `date` 确认日期，按 `YYYYMMDD.md` 建文件，跨天不追加旧文件。
- **协议分析**：优先查 FTE 服务端校验函数，而非只看 API 侧结构。
- **git 提交**：提交前核对工作日志与受影响文件是否都在变更列表中。
