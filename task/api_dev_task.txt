API 开发任务设计
任务背景:
    当前需要开发一个新版的金融系统的 API，对接三个柜台， GONE-硬件急速柜台， UTE-软急速柜台， Counter98-普通柜台.
设计文档:
    study/API 设计方案_1_1.docx

任务分析:
    基础任务:
    1. API 要接受所有加速接口和非加速接口。
        加速接口，即通用的
    1. 配置化的支持 选择登陆哪些柜台；
    2. 验密优化待定:是否登陆后，先登陆到 AGW 进行验密;
    3. 通过API登陆GONE或UTE，登陆后，校验版本号，版本号不一致，报错。
    4. 登陆异常， 登陆任何一个柜台失败，反复登陆直到成功，登陆成功后，返回登陆成功信息。
